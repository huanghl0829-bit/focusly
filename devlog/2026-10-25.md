# Dev Log — 2026-10-25

## Completed
- **Product decision recorded:** Focusly is now web-first (the web app is the product; the `Focusly/` macOS shell stays in the repo untouched).
- **Phase 1 — `verify.sh` (the roadmap's step 1):** headless verification harness. Checks `styles.css` brace balance, that `index.html` references both files, then loads `app.js` inside a stub-browser IIFE in JavaScriptCore (`osascript -l JavaScript`) and asserts 15 pure-logic tests (escaping, formatting, plan parsing, deck normalization, SRS/AI helpers, streak). Exits non-zero on any failure. Note: everything is wrapped in `(function(){ ... })()` because JXA predefines `$` (ObjC bridge) and top-level const/let may not shadow globals; the harness must `return 'VERIFY OK'` (an IIFE returns undefined otherwise).
- **Phase 2 — Backup:** Settings → "Backup your data": *Export backup* downloads `focusly-backup-YYYY-MM-DD.json` containing every `focusly.*` localStorage entry (validated payload `{kind:'focusly-backup', version, exportedAt, entries}`); *Import backup* validates the file, shows a confirm dialog (`#backup-import-dialog`), wipes current `focusly.*` keys, writes the backup, and reloads. New pending state `pendingBackupEntries` (reset in `resetTransientState`).
- **Phase 3 — Bug fixes:**
  - **Timer re-render:** the 250 ms tick no longer calls `renderFocus()`. New `updateTimerTickDom()` updates only `#timer-display`, the ring `stroke-dashoffset`, `#timer-status`, and the title. Full `renderFocus()` now runs at most every 30 s (`timerState.lastFullRender`); session persistence is throttled to every 15 s (`timerState.lastPersistAt`) via `syncActiveSession(shouldPersist)` — previously the whole workspace was JSON-serialized to localStorage 4×/second while focusing.
  - **Draft preservation:** `renderFocus()` captures the quick-task input value/selection/focus and the subject `<select>` value before rebuilding, then restores both after re-render — typing during a running timer (or any `renderApp()`) no longer loses input.
  - **Blur auto-pause:** `handleLifecycle('appInactive')` only pauses when the new `preferences.pauseOnLeave` setting is on (Settings → "Pause when I leave", default off); `systemIdle` still always pauses.
  - **Streak:** `getStreak()` starts from yesterday when today has no activity, so an unbroken history no longer reads 0 every morning.
- **Phase 4 — AI generation (bring-your-own-key):** `preferences.ai = { baseUrl, apiKey, model }` (defaults: OpenAI base URL + `gpt-4o-mini`; cloned in `createState`/`migrateState` so `DEFAULTS.ai` is never mutated). `callAI()` posts OpenAI-compatible `/chat/completions`. Materials rows gained **AI notes** / **AI cards** buttons (single-flight guard `aiStatus`, buttons disabled + labelled "Generating…" while running): notes → sanitized HTML fragment saved as `format:'html'`; cards → JSON array parsed by `parseAiCards()` into a new deck. `sanitizeAiHtml()` strips `<html/head/body/script/style/iframe/link/meta>` and code fences (rendered in the existing sandboxed iframe). Settings has base URL / key / model fields (saved on change, no re-render), a status badge ("Not set up" / "Ready · model"), and a **Test connection** action. Replaced the "Coming soon" AI row.

## Blockers / notes
- API key is stored in plain `localStorage` (like the rest of the workspace). Acceptable for a local app; worth revisiting if workspace encryption ever lands.
- AI generation needs a secure context (https or localhost) for fetch to arbitrary base URLs — fine on a hosted deploy, and CORS depends on the chosen provider (OpenAI/Z.ai/Groq allow browser CORS; some providers do not).
- The material text is truncated to 12 000 characters per AI request to bound cost.
- Import-backup cannot be exercised through the OS file picker by automation (IAB limitation); it was tested by handing `handleBackupFile()` an in-memory `File`, which covers everything except the picker itself.
- Pre-existing dark-mode nits (not touched today): weekly-goal ring and some chips still use hardcoded light colors; the native subject `<select>` renders white in dark mode.
